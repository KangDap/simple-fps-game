## Deskripsi
Project ini merupakan game FPS (First Person Shooter) sederhana yang dibuat menggunakan Unity.
Player dapat menembak objek target (sphere) menggunakan pistol M9, dengan efek visual dan audio, serta sistem penghitung hit.  
Untuk video demo game bisa ditonton [disini](https://drive.google.com/file/d/1cB1f8fsvdPe-p4J5OTSSK1H95D4_R_jf/view?usp=sharing).

---

## Fitur Utama
- Shooting system dengan pistol M9
- Bullet tracer saat menembak
- Muzzle flash & muzzle light saat menembak
- Sound effect senjata
- Hit detection
- Hits counter
- Background music
